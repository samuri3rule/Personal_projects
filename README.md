# Aiden Reedy — Personal Projects

> A collection of my software, hardware, cybersecurity projects, and homelab projects

## Overview
This repository contains my personal projects in multiple areas:
- Embedded systems (ESP32, Arduino)
- Python tooling and automation
- Security research and analysis
- Homelab and self-hosted services
- Data analysis and web projects  

Each project has its **own folder** and a dedicated README explaining its purpose, design, and usage.

## Repository Structure
- `HomeLab/`
  - `Technitium/` – Docker setup and documentation for my self-hosted Technitium DNS server.
  - `Jellyfin/` – Docker setup and documentation for my self-hosted Jellyfin media server.
- `WifiPineapple/` – Contains code and README for my Wi-Fi pineapple project.
- `WifiProbeSniffer/` – Contains code and README for my Wi-Fi probe sniffer project.
- `README.md` – This main repository overview (This Document).

## How to Use This Repo
1. Browse the project folders to find an area of interest.
2. Read the README inside each folder for setup and usage instructions.
3. Check each project's configuration files for the technologies used.
4. Respect all disclaimers and safe usage instructions per project.
